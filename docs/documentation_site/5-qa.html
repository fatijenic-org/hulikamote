Q&A

The questions a panelist may ask, and your answers. Add, edit and delete them here. Answers accept Markdown. Everything is saved to a JSON file on this computer and goes nowhere else.

How saving works, and how to start it

A web page cannot write a file by itself, so a tiny local server does it. It runs only on this computer (127.0.0.1), writes only tools/doc_site/data/qa.json, and keeps the previous version as qa.json.bak. Start it once, then open the page at the address it prints:

hulikamote_backend/venv/Scripts/python.exe tools/doc_site/serve.py --open

Without the server (page opened straight from disk), the page still works: changes are kept in this browser, and Export JSON / Import JSON let you save and load a file by hand. The green or yellow bar below tells you which mode you are in.
