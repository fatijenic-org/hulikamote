The project

What HULI-KAMOTE is, in one minute

HULI-KAMOTE is a thesis project of the College of Computing Studies in Zamboanga City: a computer-vision system that finds traffic violations in video, so officers can review them without standing at the roadside. Huli means 'caught'; kamote is slang for a reckless driver. It finds vehicles with a YOLO detector, follows each one with a tracker (DeepSORT), reads licence plates (OCR), and then decides each violation with a small, explainable rule. A person always reviews what the system flags.

How to print

Open a page in Chrome or Edge, press Ctrl+P, choose Save as PDF (or a printer), paper A4, and switch on Background graphics so the charts keep their colours. The page switches to black on white, hides the menu and starts each big section on a new page. Do this for each of the four pages.

Keeping it up to date

The tables, numbers and code are read from the repository when the site is built. After the code or the data changes, rebuild it:

hulikamote_backend/venv/Scripts/python.exe tools/doc_site/build_site.py

To use the Q&A page with saving, start the local server instead of opening the file directly. It also serves all the other pages:

hulikamote_backend/venv/Scripts/python.exe tools/doc_site/serve.py --open

What this documentation does not claim

It does not claim accuracy on Zamboanga roads. It documents what is built, how it works, what it was trained on, and what still has to be measured. Legal references marked to confirm are not yet checked with an adviser; fine amounts are not quoted.

Terms used on this page

On screen, hover or tab to any dotted word for its meaning. This list is the same meanings, for the printed copy.

DeepSORT
A tracker that matches objects between frames using where they should be (motion) and what they look like (a fingerprint).
OCR
Optical Character Recognition: reading the letters and digits in a picture.
YOLO
'You Only Look Once'. A fast family of object detectors that find all objects in a single pass over the picture.
